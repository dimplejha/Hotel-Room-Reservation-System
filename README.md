# Hotel Room Reservation System

Next.js + TypeScript implementation of the hotel room reservation assessment.

## Run

```bash
npm install
npm run dev
```

## Test

```bash
npm test
```

## Structure

- `src/app` contains the app router entry points.
- `src/features/reservation` contains booking logic, state, hooks, components, and tests.
- `src/shared` contains reusable UI primitives.
- `src/styles` contains global design tokens and animations.
